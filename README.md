# Situs resmi Slak

Kode sumber situs **[slak.studio](https://slak.studio)**, dengan salinan resmi di **[slakstudio.github.io](https://slakstudio.github.io)**.

Slak adalah framework JavaScript ala Streamlit untuk aplikasi data yang berjalan sepenuhnya di browser: tanpa server, tanpa build, cukup satu berkas `slak.js`. Situs ini sendiri dibuat dengan Slak, sehingga sekaligus menjadi contoh bahwa Slak cukup untuk membangun situs dokumentasi lengkap.

## Isi

| Folder / berkas | Isi |
|---|---|
| `index.html`, `app.js` | Aplikasi situs: menu, alamat halaman, pencarian |
| `konten/` | 45 bab dan Lampiran Buku Panduan Slak dalam Markdown |
| `halaman/` | Beranda, Galeri, Portofolio, Unduh, Lisensi, Katalog API |
| `api/katalog.js` | Katalog semua fungsi Slak dengan contohnya |
| `contoh/` | Contoh aplikasi untuk Galeri |
| `playground/` | Playground: tulis dan jalankan kode Slak di browser |
| `bab/` | Halaman pratinjau tautan per bab |

## Membaca tanpa internet

Unduh repo ini sebagai zip (**Code › Download ZIP**), ekstrak, lalu buka `index.html` dengan klik dua kali.

## Unduhan

`slak.js`, paket Slak, Slak Studio untuk Windows, dan Buku Panduan PDF ada di
[GitHub Releases](https://github.com/slakstudio/slak/releases).

## Memperbaiki isi

Untuk memperbaiki salah ketik atau penjelasan, ubah berkas `.md` bab yang bersangkutan di `konten/`, lalu kirim pull request. Panduan lengkap ada di [CARA-MERAWAT.md](CARA-MERAWAT.md).
